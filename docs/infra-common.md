## 호스트 / 계정 정본 (경로를 기억으로 쓰지 말 것)

| 호스트 | 계정 | `sudo` | 주요 경로 |
|---|---|---|---|
| PVE 호스트 (`pve`, `10.10.10.1`) | **root** | **붙이지 않는다** (이미 root) | `/opt/pve-net-broker` · `/root/pve-vm-guardian` |
| `.42` reverse-proxy VM (hostname `dev`) | **riaveda** | **필요** (root 로그인 불가) | `~/swp-iot-portal-frontend` (포털 소스) · `~/reverse-proxy/nginx` (nginx conf 스테이지) |

⚠️ **포털 소스는 `~/swp-iot-portal-frontend` 다 — `~/portal` 이 아니다.**
`portal` 은 구 `portal-frontend` 계정 시절 이름이라, 그대로 쓰면
`cd: /home/riaveda/portal: No such file or directory` 가 난다 (2026-09-16 실제로 틀렸다).

서빙 심볼릭 확인 (`.42`):
```bash
readlink -f /var/www/reverse-proxy
```

## 한 레포만 고쳐서는 안 끝나는 것 (교차 의존)

| 바꾸는 것 | 같이 봐야 하는 곳 |
|---|---|
| 서비스 IP/포트 | `nat-rules.sh`(L4 포워딩) **와** `_service-routes.conf`(L7 라우팅) 가 함께 맞아야 한다 |
| 새 서비스 경로 추가 | ① 라우트(`_service-routes.conf`) ② https 유도 목록(`$ap_redirect_path`) ③ 포털 카드(`services.js`) — **셋 다 수동이다.** 하나만 하면 반쪽만 동작한다 |
| 포털 서빙 경로 이동 | `pnbctl proxy deploy` 는 nginx conf 만 rsync 한다. `/var/www/reverse-proxy` 심볼릭 repoint 는 **어느 자동화도 해 주지 않는다** — 사람이 한 번 해야 한다 |

## 응답 규칙 (Claude → 사용자)

> 이 절은 세 레포 `CLAUDE.md` 에 **같은 내용으로 복제**돼 있다 (자동 로드를 위해).
> 여기가 원본이다 — **고칠 때는 여기와 세 레포를 함께 고친다.**

내가(Claude) 사용자에게 보내는 **모든 메시지의 맨 끝**에 아래 두 절이 이 순서로 들어간다.
중간 진행 보고·질문·짧은 답변도 예외 없다.

### ① 전체 내용 — 간략하되 일목요연하게
- 무엇을 왜 바꿨는지(또는 무엇을 알아냈는지)를 **표·불릿으로 압축**한다. 긴 산문 금지.
- 되짚을 근거를 함께 적는다 — 파일 경로, 커밋 해시, 브랜치.
- 지시받은 것 중 **안 한 게 있으면 반드시 여기에 이유와 함께 적는다.** 조용히 빠뜨리지 않는다.

### ② 「지금 하실 것」 — 제목·구분선까지 이 형식 그대로

마지막 절의 제목은 **반드시 `지금 하실 것`**, 앞에 `---` 수평선을 둔다. 제목을 바꾸지 않는다.

**⛔ CLI 를 표 안이나 인라인 코드(`...`)로 주지 않는다.**
표 셀·인라인 코드에는 **복사 버튼이 없어 사용자가 드래그해서 긁어야 한다.**
명령은 **반드시 ```bash 펜스 코드블록**으로 준다 — 거기엔 복사 버튼이 붙는다.

나머지 규칙:
- 사용자가 **직접** 해야 하는 것만. **없으면 "없음" 이라고 쓴다** — 절을 비우거나 생략하지 않는다.
  없을 땐 다음이 무슨 차례인지 한 줄 덧붙인다.
- **실행 위치와 계정은 코드블록 바로 위 한 줄**에 굵게 적는다 (블록 안에 주석으로 넣지 않는다).
  호스트가 다르면 같은 명령도 다른 결과를 낸다 — 위 "호스트/계정 정본" 표 참조.
- **코드블록 안에는 명령만.** 프롬프트 기호(`$`)나 설명 주석을 섞지 않는다 — 복사하면 같이 붙는다.
- 명령이 여러 개면 **번호를 매기고 각각 별도 코드블록**으로. 한 블록에 몰아넣으면 한 번에
  복사돼 순서 확인을 건너뛴다. 단 **같은 호스트에서 이어 치는 것은 `&&` 로 한 줄**에 묶는다.
- 경로는 기억으로 쓰지 않고 위 "호스트/계정 정본" 표에서 확인한 실제 경로로 쓴다.
- 담당자 답변 대기처럼 **명령이 아닌 할 일**은 코드블록 없이 따로 묶어 적는다.
